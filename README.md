# FoodBridge — Presentation Dashboard

A presentation-ready food redistribution dashboard styled similarly to a clean medicine-management/admin dashboard.

## Includes
- Fixed left sidebar
- Dashboard heading and action button
- Summary cards
- Recent donations table
- Add Donation form
- Community impact section
- Alerts
- Responsive design
- Working frontend demo for adding donations

## Run
Open `index.html` directly, or use VS Code Live Server.

## GitHub Pages
Upload the project to a GitHub repository and enable GitHub Pages from Settings → Pages.
